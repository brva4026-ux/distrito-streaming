# ⚠️ INSTRUCCIONES PARA LIMPIAR CACHÉ

Si los reportes aún no aparecen después de actualizar, sigue estos pasos:

## 1. Limpiar Caché del Navegador

### En Windows/Linux:
```
Presiona: Ctrl + Shift + Delete
```

### En Mac:
```
Presiona: Cmd + Shift + Delete
```

## 2. Pasos en el Navegador:

1. Abre DevTools (F12)
2. Ve a la pestaña **Application** o **Storage**
3. Click en **Clear Site Data** o similar
4. Asegúrate de que esté seleccionado:
   - ✅ Cookies
   - ✅ Cached images and files
   - ✅ Local storage
   - ✅ Session storage

5. Click en **Clear**

## 3. Recarga la Página

```
Presiona: Ctrl + F5 (fuerza recarga sin caché)
```

## 4. Verifica los Cambios

Ahora deberías ver:
- ✅ Tarjetas de reporte mejoradas
- ✅ Con colores y diseño profesional
- ✅ Estados visibles
- ✅ Tus reportes listados

---

## Si Aún No Funciona:

### Opción A: Abre Consola (F12)
Busca errores rojos y reporta

### Opción B: Verifica que los archivos existan
```
- reports-styles.css
- reports-functions.js
- reports-monkey-patch.js
- reports-bootstrap.js
```

### Opción C: Reinicia completamente el navegador
Cierra todas las pestañas y vuelve a abrir
