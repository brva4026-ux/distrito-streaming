## 🎯 CÓMO USAR

### 1. Ver Tus Reportes

1. Accede a la sección **"Reportes y Soporte"**
2. Verás una lista de tus reportes ordenados por:
   - Reportes sin resolver primero
   - Más recientes arriba

3. Cada reporte muestra:
   - ✅ Estado (Abierto, En revisión, En proceso, Resuelto, Rechazado)
   - 📦 Categoría del problema
   - 🎯 Prioridad (Normal/Urgente/Crítico)
   - ⏱️ Tiempo transcurrido
   - 💬 Número de mensajes
   - 📎 Archivos adjuntos

### 2. Crear un Nuevo Reporte

1. Click en "Crear Nuevo Reporte"
2. Selecciona la compra con problema
3. Elige la categoría:
   - 📦 Producto no llegó
   - ⚠️ Defectuoso/No funciona
   - 🔐 Cuenta no funciona
   - 🚫 Acceso denegado
   - ❓ Otro

4. Completa los campos:
   - **Asunto** - Resumen corto
   - **Descripción** - Detalles completos
   - **Datos de cuenta** - Info adicional

5. Adjunta evidencia (opcional)

6. Click en "Enviar Reporte"

### 3. Monitorear Progreso

El reporte mostrará:
- **Pipeline visual** con estado actual
- **Timeline** de todos los eventos
- **Mensajes** del administrador
- **Archivos** compartidos
